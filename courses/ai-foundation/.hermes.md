# UKAIC AI Foundation — Project Context

Training pack for the **UKAIC AI Foundation** certification (UK AI Council),
built to *UKAIC AI Foundation Technical Syllabus v1.0* (ref `SYL_AIF`, Public Release).

**Deploy target: local only.** The user explicitly chose a local site, not GitHub Pages.
Do not create a repository or enable Pages unless asked.

## Layout

```
UKAIC-AI-Foundation/
├── index.html …          ← GENERATED site pages (do not hand-edit)
├── domains/*.html        ← GENERATED (8 pages, one per domain)
├── assets/css/style.css  ← hand-authored theme (white/navy + dark mode)
├── assets/js/site.js     ← hand-authored behaviour (theme, mobile nav, progress)
├── _build_site.py        ← SITE BUILDER: metadata + shared chrome. Edit this.
├── serve.py              ← local preview server with custom 404
├── 404.html, robots.txt  ← GENERATED
├── quizzes/              ← quiz HTML + build/test scripts
├── lessons/              ← lesson plans (Markdown)
├── decks/                ← slide decks (.pptx)
└── research/             ← RESEARCH-NOTES.md (sourced evidence base)
```

## Non-negotiables

- **Never hand-edit a generated page.** Change `_build_site.py` and re-run it. The nav,
  footer and page chrome live there; hand edits get overwritten and drift between pages.
- **The site reports real inventory.** Resource status is derived by scanning `lessons/`,
  `decks/` and `quizzes/` at build time. Unbuilt resources render as plain text with a
  "Planned" badge — never as a link to a file that does not exist.
- **Vendor neutrality.** The exam is vendor-neutral and no question requires knowledge of
  a named commercial product. Frame every demo as a *category* of tool. This applies to
  site copy, lessons and decks alike.
- **Never use real personal, confidential or commercially sensitive data** in demos.
- **SYL_AIF v1.0 governs structure and weightings** (14/17/14/19/15/19/12/10). Where the
  master workplace guide or any other source conflicts with the syllabus, the syllabus wins.
  Note the master guide's §1.5 describes an *older four-domain* framework — do not use it
  as the structural basis for anything.
- **Accessibility is tested, not asserted.** WCAG 2.1 AA, contrast checked in both themes,
  including buttons and pills (body text alone passes while buttons become invisible).

## Course facts

- 8 domains · ~21 hours delivery · 31-question quiz per domain · 120-question final.
- Final exam: 120 MCQs, 120 minutes, closed book, proctored, pass mark 70% (84/120).
- Certification is awarded **only** by passing the official exam. Training, quizzes and
  the mock final confer nothing. The pack is independent and not endorsed by UKAIC.

| Bank file | Questions | Purpose |
|---|---|---|
| `_q_domain4.py`, `_q_domain6.py` | 31 each | Section quiz **and** final-exam source |
| `_q_domain8.py` | 31 | Section quiz **and** final-exam source |
| `_q_domains_12357.py` (Q1/Q3/Q5/Q7) | 14/14/15/12 | **Final-exam seeds only** |
| `_q_domain2.py` (Q2) | 18 | **Final-exam seed only** |

The D1/2/3/5/7 banks are sized to the **exam weighting**, not to 31. They were written to
seed the 120-question paper. A section quiz needs 31 questions, so those five domains
still need their own banks written — do not treat the existing files as a finished
section quiz.

## Integrity rules (user-mandated) — all verified in the shipped papers

1. **Randomised question order** — enabled in all four papers.
2. **Copy/paste disabled** — `['copy','cut','paste','contextmenu']` blocked, with
   `user-select:none` scoped to the question container (not `body`). Verify by
   **dispatching real events and reading `defaultPrevented`**, not by grepping for
   listeners: the single blocked-events list defeats a per-event grep pattern and gives a
   false negative. This is a deterrent, not a security control.
3. **No longest-answer tell** — correct option is strictly longest in 10–17% of shipped
   questions (chance = 25%), so length carries no signal. `_balance.py` pads distractors
   at build time; audit the **built HTML**, not the source bank (the source banks still
   read 73–100% biased because balancing happens during the build).
