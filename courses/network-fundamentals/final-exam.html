Final exam

The course consolidates in Session 12 and prepares you for the CompTIA Security+ SY0-701 examination.

Security+ SY0-701 examination format

Questions: maximum of 90 · Time: 90 minutes · Format: multiple-choice and performance-based questions · Pass mark: 750 on a scale of 100–900.

The exam is closed book and proctored. CompTIA does not publish a fixed question count; the maximum is 90.

Security+ exam domains

The SY0-701 examination is weighted across five domains. The session numbers show where this course covers each one.

DomainWeight Covered in
1. General Security Concepts12% Sessions 4, 5, 12
2. Threats, Vulnerabilities & Mitigations22% Sessions 5, 9, 10
3. Security Architecture18% Sessions 1–3, 8, 9
4. Security Operations28% Sessions 10, 11
5. Security Program Management & Oversight20% Sessions 12, and threaded throughout

How to prepare

  1. Work the twelve sessions in order. The network foundation sessions are not optional — Security+ assumes them.
  2. Pass every session quiz twice. Twenty questions each, with explanations. Aim for a clean run before moving on.
  3. Use the glossary. 216 terms across the course, tagged with the session they come from.
  4. Know the numbers. Subnet formulas, port numbers, key lengths, control categories — these are quick marks.
  5. Revisit your cautions. Every session lists the specific errors that lose marks in that topic.

Practice exam

A full-length mock paper, 90 questions, weighted to the same domain split as the real examination. Take it in one sitting with no notes, then read every explanation.
