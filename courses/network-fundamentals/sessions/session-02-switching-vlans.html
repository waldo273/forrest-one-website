Switching, VLANs & Network Architectures

Layer 2 in action: MAC addresses and switch forwarding, VLAN segmentation and 802.1Q trunking, Spanning Tree loop prevention — the mechanisms that carry traffic and the controls that keep segments apart.

Learning outcomes

By the end of this session, candidates will be able to:

  • Explain why switches forward frames rather than packets, and name the PDU at layer 2.
  • Describe the structure of a MAC address, including the OUI and its forensic value.
  • Explain the learn, look up, forward and flood behaviour of a switch forwarding table.
  • Describe VLANs and their security purposes, including guest isolation, blast-radius containment and limiting lateral movement.
  • Explain 802.1Q tagging, trunk ports and access ports, and the VLAN hopping attacks that target native VLAN misconfiguration.
  • Explain the native VLAN risk and best-practice mitigations: move VLAN 1, prune unused VLANs and restrict trunk allowed lists.
  • Describe the switching-loop problem and how STP solves it.
  • Explain root bridge election, root ports and STP port states.
  • Describe STP attacks and the defensive features BPDU Guard, Root Guard and port security.
  • Map network segments to security zones, including the DMZ concept with external and internal firewalls, and explain microsegmentation.

What this session is about

What this session covers, with teaching notes area by area.

2A — Layer 2 switching

Switches forward frames at layer 2 using MAC addresses. On receipt: learn the source MAC and port, look up the destination, forward to the matching port — or flood if unknown. Broadcasts always flood. CAM-table overflow (MAC flooding) degrades a switch into hub mode, letting an attacker see all frames on the segment.

2B — VLANs & trunking

VLANs segment one physical switch into logical broadcast domains — the core containment control. Trunk ports carry tagged frames between switches via 802.1Q; access ports carry one untagged VLAN. Segmentation reduces the attack surface, contains blast radius and blocks lateral movement. The default native VLAN (VLAN 1) is an attack surface — change it, prune unused VLANs and restrict trunk allowed lists. VLAN hopping crosses boundaries by switch spoofing (negotiating a trunk) or double tagging (native VLAN spoof). Microsegmentation takes this further, isolating individual workloads via SDN.

2C — Spanning Tree

Redundant links create loops; STP blocks redundant ports for a loop-free topology. The root bridge is the lowest bridge ID; each non-root switch picks the lowest-cost root port. Ports are blocking, listening, learning, forwarding or disabled. RSTP (802.1w) converges in seconds. BPDU Guard and Root Guard stop rogue-root attacks, and port security limits MACs per port.

2D — Architectures

Segments become security zones: DMZ for public services, bracketed by external and internal firewalls with a proxy between; management isolated; workstations separate from servers; unmanaged IoT devices on their own segment. A campus has access, distribution and core layers. Segmentation limits blast radius and blocks lateral movement — containment is an architectural control that the exam treats across Domain 3 and Domain 4.
