Core concepts

2A - Layer 2 switching

Switches forward frames at layer 2 using MAC addresses. On receipt: learn the source MAC and port, look up the destination, forward to the matching port - or flood if unknown. Broadcasts always flood. CAM-table overflow (MAC flooding) degrades a switch into hub mode, letting an attacker see all frames on the segment.

2B - VLANs & trunking

VLANs segment one physical switch into logical broadcast domains - the core containment control. Trunk ports carry tagged frames between switches via 802.1Q; access ports carry one untagged VLAN. Segmentation reduces the attack surface, contains blast radius and blocks lateral movement. The default native VLAN (VLAN 1) is an attack surface - change it, prune unused VLANs and restrict trunk allowed lists. VLAN hopping crosses boundaries by switch spoofing (negotiating a trunk) or double tagging (native VLAN spoof). Microsegmentation takes this further, isolating individual workloads via SDN.

2C - Spanning Tree

Redundant links create loops; STP blocks redundant ports for a loop-free topology. The root bridge is the lowest bridge ID; each non-root switch picks the lowest-cost root port. Ports are blocking, listening, learning, forwarding or disabled. RSTP (802.1w) converges in seconds. BPDU Guard and Root Guard stop rogue-root attacks, and port security limits MACs per port.

2D - Architectures

Segments become security zones: DMZ for public services, bracketed by external and internal firewalls with a proxy between; management isolated; workstations separate from servers; unmanaged IoT devices on their own segment. A campus has access, distribution and core layers. Segmentation limits blast radius and blocks lateral movement - containment is an architectural control that the exam treats across Domain 3 and Domain 4.

Practical cautions

Where marks are lost

  • Do not confuse switches (layer 2, frames) with routers (layer 3, packets).
  • Do not leave the native VLAN at VLAN 1 - it is a known attack surface.
  • Do not assume VLANs make the network faster - they make it segmented.
  • Do not confuse BPDU Guard (shuts the port) with Root Guard (stops root takeover).
  • Do not ignore unknown-unicast floods in a capture - they may be MAC flooding.
  • Do not confuse VLAN hopping methods: switch spoofing negotiates a trunk; double tagging spoofs the native VLAN.
  • Do not treat segmentation as only separating departments - it is a lateral movement and blast radius control.

Exam tips for Session 02

Security+ alignment

  • Learn, look up, forward, flood - the switch behaviour sequence is a classic question.
  • The native VLAN rule is examinable: move it, prune unused VLANs, restrict trunk allowed lists.
  • STP port states and the guard features appear in scenario questions - know which guard does what.
  • Segmentation-as-control answers many 'contain the breach' and lateral movement questions.
  • VLAN hopping: distinguish switch spoofing from double tagging in attack questions.

Self-check

Answer these from memory before you take the quiz. If you cannot answer one, revisit the matching concept above.

  1. What three operations does a switch perform when it receives a frame?
  2. How does unknown unicast forwarding differ from known unicast forwarding?
  3. What problem does STP solve, and how?
  4. What is the difference between a trunk port and an access port?
  5. How can an attacker exploit STP, and which feature stops it?
  6. Name the two VLAN hopping methods and the mitigations for each.
  7. How does segmentation limit blast radius and block lateral movement?
  8. What components bracket a DMZ, and why?
