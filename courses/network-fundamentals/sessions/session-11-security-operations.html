Security Operations: Monitoring, IR & Forensics

Alerting and monitoring concepts, the incident response lifecycle, digital forensics and evidence handling, and the indicators of malicious activity across the estate.

11A11B11C11D

Learning outcomes

By the end of this session, candidates will be able to:

  • Describe monitoring data sources: logs, flow data, packet capture, sensors, and SIEM aggregation and correlation.
  • Explain alerting: baselines, thresholds, alert fatigue, real-time alerting versus trend analysis.
  • Describe the incident response lifecycle: preparation, detection and analysis, containment, eradication, recovery, lessons learned.
  • Classify incidents and assign severity levels to drive response urgency.
  • Explain containment strategy and its evidence trade-offs.
  • Describe digital forensics basics: evidence types, admissibility, write blockers, preservation-first mindset, authorisation.
  • Explain chain of custody and why breaking it makes evidence inadmissible.
  • Explain the order of volatility and capture priority, including memory forensics.
  • Describe preservation: imaging, hashing, legal hold and log retention.
  • Apply forensic techniques: file carving, timeline analysis, hash analysis, metadata analysis.
  • Explain after-action review and root cause analysis to prevent recurrence.
  • Recognise indicators of malicious activity: malware, network, application and behavioural.

What this session is about

What this session covers, with teaching notes area by area.

11A — Monitoring

Sources: logs (security, system, application, network device, firewall), flow (NetFlow/sFlow), packet capture, sensors, and the SIEM that aggregates and correlates them. Baselines define normal; thresholds alert on deviation; alert fatigue buries real incidents. Pair real-time alerting with trend analysis and tune alerts to cut false positives.

11B — Incident response

Six phases: preparation (before!), detection and analysis (confirm, scope, classify, grade severity), containment (evidence trade-off), eradication, recovery (validated restores, intensified monitoring), lessons learned. Classify each incident and set severity low to critical to drive urgency. Close with an after-action review and root cause analysis so the incident cannot recur.

11C — Forensics

Evidence must be admissible and lawful to collect (warrant or consent). Chain of custody: every handover documented. Order of volatility: registers, RAM, then disk — memory forensics often reveals what logs miss. Preservation: use write blockers, image and hash before analysis, apply legal hold, retain logs. Techniques: carving, timeline analysis, hash analysis, metadata analysis.

11D — Indicators

Malware: viruses, worms, Trojans, ransomware, spyware, rootkits, botnets. Network: port scanning, unusual traffic, data exfiltration, C2 beacons. Application: web log probes, phishing email, privilege escalation, privilege usage at odd hours. Behavioural: repeated failed logins, unusual times, impossible travel, data spikes.
