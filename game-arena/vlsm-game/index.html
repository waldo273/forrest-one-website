VLSM Subnetting Game

Master Variable Length Subnet Masking — CCNA 1

What is this?

This game tests your ability to calculate VLSM (Variable Length Subnet Mask) schemes. You are given a base network and host requirements for multiple subnets. Your task is to determine the correct subnet mask, CIDR notation, network ID, usable IP range, and broadcast address for each subnet — just like you would in a real enterprise network design.

Levels

Level 1
192.168.x.0/24
3 subnets
40–100 hosts
Level 2
172.16.x.0/16
5 subnets
2–500 hosts
Level 3
10.x.x.0/8
7 subnets
2–5,000 hosts

Complete 5 challenges in a row at each level to unlock the next.

Scoring

  • +100 points for a correct Level 1 scheme
  • +200 points for a correct Level 2 scheme
  • +500 points for a correct Level 3 scheme
  • +5 points for each correct field checked individually
  • -25 points for first hint, -75 for subsequent hints
  • Score carries over across all levels and is saved to your browser
