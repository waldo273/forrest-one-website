CREST Practice Labs

Hands-on labs for the CREST Practitioner certifications

A self-contained Docker environment for the CREST Practitioner Intrusion Analyst (CPIA) and CREST Practitioner Security Analyst (CPSA) certification domains, plus a full Kali Linux desktop in the browser. Bring up the console on your own machine and work the exercises.

Checking lab console…

The CREST lab is a self-contained Docker environment that runs locally. When it is running, the multi-page console is available at:

http://defiant.tail57a85e.ts.net:8020

The console has three tabs: /cpia for intrusion analysis, /cpsa for security assessment, and /kali for a full Kali desktop, each with in-browser terminals and a doc pack.

The lab must be running on the host for this link to respond. It is not hosted on this website: the button opens the console on your network.

The Lab Ranges

Intrusion Analysis 🔎

CPIA, Practitioner Intrusion Analyst

Forensic analysis and incident response. Packet capture triage, Windows Event Log timelines, memory forensics with Volatility 3, live incident reconstruction, and static malware triage.

Security Assessment 🛡️

CPSA, Practitioner Security Analyst

Security assessment of a deliberately weak network-services host. Host discovery, service enumeration, credential testing, NFS & RPC enumeration, SMTP user enumeration, and web application testing.

Full Kali Desktop 🖥️

Kali, Browser Desktop Sandbox

A complete Kali Linux rolling desktop you open in any browser (HTTPS, self-signed cert, so accept the warning). No login needed: the desktop opens straight away. The full security toolset is installed, and a shared workspace folder moves files in and out of the desktop.

Vulnerability Scanning 🔍

Nessus, Vulnerability Scanner

Tenable Nessus (Docker, online) for credentialed and unauthenticated scanning of the lab range. Reachable over HTTPS at its own address on the network.

Open Nessus

Evidence-Based 📄

Findings & Reports

Every lab is designed around the core certification skill: evidence-based assessment. Record your findings, correlate scanners with manual probes, and produce a professional report.

One Desktop, Every Lab Inside It

The labs run inside the Kali desktop, not on separate machines. Open the desktop and every target is already there, reachable by name, with the practice evidence mounted and the toolset installed. Nothing to configure, no addresses to remember.
