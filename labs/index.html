CREST Practice Labs

Hands-on labs for the CREST Practitioner certifications

A self-contained Docker environment for the CREST Practitioner Intrusion Analyst (CPIA) and CREST Practitioner Security Analyst (CPSA) certification domains. Bring up the console on your own machine and work the exercises.

Open Lab Console Explore the ranges

The Lab Ranges

Intrusion Analysis 🔎

CPIA — Practitioner Intrusion Analyst

Forensic analysis and incident response. Packet capture triage, Windows Event Log timelines, memory forensics with Volatility 3, live incident reconstruction, and static malware triage.

Security Assessment 🛡️

CPSA — Practitioner Security Analyst

Security assessment of a deliberately weak network-services host. Host discovery, service enumeration, credential testing, NFS & RPC enumeration, SMTP user enumeration, and web application testing.

Evidence-Based 📄

Findings & Reports

Every lab is designed around the core certification skill: evidence-based assessment. Record your findings, correlate scanners with manual probes, and produce a professional report.

Run the labs on your machine

The CREST lab is a self-contained Docker environment that runs locally. When it is running, the multi-page console is available at:

http://172.16.0.100:8020

The console has two dashboards — /cpia for intrusion analysis and /cpsa for security assessment — plus an in-browser terminal for each lab exercise.

The lab must be running on the host for this link to respond. It is not hosted on this website — the button opens the console on your network.
